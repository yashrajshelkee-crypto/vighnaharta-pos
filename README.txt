HOTEL SHREE VIGHNAHARTA POS - INSTALL GUIDE
1. Upload this whole folder to any free HTTPS static host (Netlify Drop, GitHub Pages, Cloudflare Pages).
2. Open the link ONCE on the hotel phone in Chrome with internet, wait 5 seconds.
3. Chrome menu -> Install app / Add to Home screen. After that it works fully offline.
4. Settings: enter hotel details, UPI ID, beneficiary name, PIN. Confirm the Handi Half/Full labels.
5. Data stays only on this phone. Settings -> Export JSON weekly and keep the file in WhatsApp/Drive.
Note: the QR printed on the menu is a Google review QR, not a payment QR. Use your UPI ID or upload your payment QR.
